# arXiv + bioRxiv 每日新知识插件 Todo List

## 目标

做一个每天自动获取 arXiv 和 bioRxiv 新论文的插件。

插件不做完整镜像，不默认下载所有 PDF。  
第一目标是：每天获取新论文信息，筛出和课题组方向相关的论文，并生成简洁的每日简报。

## Stage 1: Metadata MVP

目标：先做一个能稳定运行的最小版本。

### 要做

- [ ] 接入 arXiv metadata 数据源
- [ ] 接入 bioRxiv metadata 数据源
- [ ] 每天自动同步新论文信息
- [ ] 保存论文基本信息到本地数据库
- [ ] 支持按关键词搜索论文
- [ ] 支持按日期、来源、分类筛选论文
- [ ] 生成每日论文简报

### 保存的信息

- [ ] 标题
- [ ] 作者
- [ ] 摘要
- [ ] 来源：arXiv 或 bioRxiv
- [ ] 分类或学科
- [ ] 发布日期
- [ ] arXiv ID 或 DOI
- [ ] 原文链接
- [ ] PDF 链接

### 不做

- [ ] 不下载所有 PDF
- [ ] 不做全站 arXiv 镜像
- [ ] 不做复杂全文解析
- [ ] 不做大规模向量数据库

### 完成效果

用户可以问：

```text
今天有没有和 protein design / single-cell / foundation model 相关的新论文？
```

插件返回：

```text
今日相关论文 Top 10

1. 论文标题
   来源：bioRxiv
   日期：2026-06-17
   相关原因：摘要中提到 single-cell 和 foundation model
   简短摘要：……
   链接：……
```

## Stage 2: 课题方向筛选

目标：让插件更懂课题组关心什么。

### 要做

- [ ] 支持配置课题组研究方向
- [ ] 支持配置关键词
- [ ] 支持配置重点分类
- [ ] 支持配置排除关键词
- [ ] 给每天的新论文打相关性分数
- [ ] 自动选出高相关论文
- [ ] 为每篇推荐论文生成推荐理由
- [ ] 支持多个研究方向 profile

### 示例配置

```yaml
profile: lab_default
keywords:
  - protein design
  - single-cell
  - gene regulatory network
  - foundation model
arxiv_categories:
  - q-bio
  - cs.LG
  - stat.ML
biorxiv_subjects:
  - bioinformatics
  - genomics
  - systems biology
```

### 完成效果

插件每天自动输出：

```text
今日建议重点关注：5 篇
今日中等相关：20 篇
今日低相关缓存：若干篇
```

长期保留高相关论文。  
低相关论文只短期缓存，避免数据库无限变大。

## Stage 3: 高价值论文全文处理

目标：只对值得读的论文下载和解析全文。

### 要做

- [ ] 支持手动下载某篇论文全文
- [ ] 支持自动下载高相关论文全文
- [ ] 下载前检查本地缓存，避免重复下载
- [ ] 加入下载队列和限速
- [ ] 解析 PDF 或 LaTeX source
- [ ] 把全文切成可检索片段
- [ ] 支持基于全文问答
- [ ] 支持生成详细论文笔记

### 不做

- [ ] 不批量下载所有 PDF
- [ ] 不让 agent 直接高并发访问 arXiv
- [ ] 不重复下载同一篇论文

### 完成效果

用户可以问：

```text
深入分析今天最相关的 3 篇论文，说明它们和我们课题的关系。
```

插件可以返回：

```text
1. 论文核心问题
2. 方法简介
3. 主要结果
4. 和课题组方向的关系
5. 是否值得精读
6. 可以借鉴的实验或 baseline
```

## 最终形态

最终插件应该像一个“每日科研雷达”。

它每天自动做三件事：

- [ ] 获取新论文
- [ ] 筛出相关论文
- [ ] 总结值得看的新知识

它不是简单搜索工具。  
它的价值是帮助课题组更快发现有用的新论文。
