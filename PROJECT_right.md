## 当前目标

- 右侧结果栏不是日志 dump。它必须按对象类型展示 Browser、Screen、Terminal、Files、References 等 Cursor-like panes，并以可点击 refs 驱动。
- GUI -> TUI 只发送终端等价文本、focus/confirmation 结果或只读 projection；TUI -> GUI 只通过 declared GUI intents。
- BrowserRuntime、Computer Use、Files、Terminal、References 都必须作为 Agent Host 可组合模块呈现；GUI 只做 presentation / focus / confirmation / resource projection。
- Terminal 允许登记为 host-owned live PTY 豁免：用户手动打开 Terminal pane 后，可直接连接 workspace writer 管理的 shell PTY，输入/resize/stop 走 terminal WebSocket 控制面；该豁免只适用于 Terminal pane 自身，不适用于 Browser、Screen、Files、References，也不允许 GUI 将 terminal transcript 当作 completion/evidence verdict。

- 所有修改必须通用，不能为当前页面、截图、URL、文件名或历史 run 写硬编码补丁。

- GUI -> TUI 只发送终端等价文本、focus/confirmation 结果或只读 projection；TUI -> GUI 只通过 declared GUI intents。
- 右侧结果栏不是日志 dump。它必须按对象类型展示 Browser、Screen、Terminal、Files、References 等 Cursor-like panes，并以可点击 refs 驱动。
- 大 payload、截图、录屏、terminal transcript、DOM snapshot、artifact、audit 和 replay 必须 refs-first；不得内联 raw screenshot/base64/provider payload/secret。

## 模块化设计原则

- 公共函数只有四个：`module.describe`、`module.query`、`module.read`、`module.invoke`。
- `describe/query/read` 必须只读；只有 `invoke` 可以有副作用。未声明 module function、intent、facet 或 ref prefix 必须 fail closed。
- `list/search` 收敛为 `query`，`stat` 收敛为 `read({ includeMeta: true })`，`watch/subscribe/present/ask_user/apply_batch` 收敛为具体 `invoke` intent。
- Agent Host 负责编排 semantic pipeline；模块不得直接 import 或调用其它模块；GUI 可以展示 pipeline trace，但不决定 pipeline。
- trace-first 是默认要求：跨模块组合必须记录 step id、moduleId、function、intent/query/ref、input/result summary、refs、approval、operation、timing、status 和 parent/child relation。

## 体验对齐原则

- 用户体验尽可能与 Cursor Agent desktop app 的稳定信息架构对齐；对照记录只保留通用行为，不固化一次性坐标、URL、截图或历史 run。
- 左侧栏只管理 workspace/project/thread 的可视化投影、选择、排序、归档、置顶、草稿和上下文入口；真实任务启动、工具选择、repair、sub agent 创建和 workspace 写入仍由 Agent Host 执行并产生 trace。
- 聊天中间栏只展示用户消息、assistant 进度句、`Worked for ...` / `Explored ...` 聚合项、动作行和最终回答；旧 SciForge summary、重复 transcript、不可交互过程块和占位 progress 应删除。
- 右侧结果栏必须按对象渲染：Browser 展示真实可交互网页或明确 blocked/error；Screen 展示 Computer Use virtual screen/replay frames；Terminal 展示 Cursor-like terminal session；Files 展示 workspace file viewer/editor；References 展示对象 refs 和 provenance。
- 点击对象引用必须打开或聚焦右侧对象；把引用插回输入框只能通过显式引用/上下文菜单完成。

### Terminal Live PTY 豁免

- 目的：Terminal pane 按用户反馈应“和系统终端一样即可”，不能因为结果对象展示架构而失去真实输入、运行和停止能力。
- 豁免边界：Right Pane Terminal 可以启动/附着 workspace writer 持有的 shell PTY；GUI 只负责 xterm presentation 和 WebSocket 事件转发，进程生命周期、cwd、transcript mirror 和 stop 仍由 host 拥有。
- 安全边界：Browser/Screen/Files/References 继续 refs-first；terminal transcript 只作为 terminal/provenance ref，不作为任务成功判定；secret/env/raw provider payload 仍不得内联到 evidence。
- 通用性：PTY session id、workspacePath、cwd、shell、rows/cols 均来自配置或 host 响应；不得为当前页面、当前 URL、当前 run 或历史截图硬编码。
- 当前决策冻结（2026-06-01）：关闭 Terminal tab 必须 stop 对应 PTY；Workspace Writer URL 指错服务或缺少 terminal capability 时，Terminal 打开前必须先展示 typed diagnostic，并提供重新检查、启动服务、切换候选 writer 或打开 Settings 的一键动作。本轮用户要求“现在不改代码”时，只更新/复核任务文档；后续若再改实现，必须重新补验证命令和真实 UI evidence。

### Browser Host Surface 豁免 / 技术路线

- 结论：外部 HTTP/HTTPS HTML 不能再把 iframe/proxy/snapshot 当作 live browser 或第二画面真相源；`BrowserHostSession` 是唯一 live browser owner。
- 归属边界：Host 持有真实浏览器会话、导航状态、click/type/press/scroll 输入、native/streaming live surface、frame/screenshot/DOM/AX/console/network/search refs；右侧 Browser pane 只做 viewer、focus、confirmation、地址栏和 refs-first presentation。
- Shell 边界：Tauri/Electron/Web 只是 shell/adapter。Electron 可用 WebContentsView/WebView/独立 Chromium surface 作为宿主 adapter，Tauri/Web 可展示同一 host session 的 frame stream；任何 shell 都不得把 iframe、proxy、`<webview>`、历史截图、PDF/document、replay、旧 frame 或系统 popup 标记为 live browser owner、第二真相源或替代交互路径。
- 工作流边界：`browser_search` 是原子搜索工具，由 workspace runtime 打开 `BrowserHostSession` 执行真实搜索并返回 bounded summary、finalUrl、searchResultRef、screenshotRef、domSnapshotRef、axSnapshotRef、consoleLogRef、networkLogRef。
- Screen 边界：VirtualAppScreen 同样采用单一 native/streaming live surface；snapshot/replay/PDF/document 只能是 evidence/artifact，不能作为第二个 Screen 交互真相源或替代交互路径。
