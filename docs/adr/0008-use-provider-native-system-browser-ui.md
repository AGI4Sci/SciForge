# Use provider-native system-browser UI

Shared Documents V1 opens the selected Document Provider's Web editor through a main-validated opaque DocumentLaunchTarget and does not contribute a document panel or reuse Browser Preview as an editor. OpenContent is one optional Provider; a future SciForge-hosted editor remains owned by its Document Provider rather than Shared Documents. A future generic in-app browser may consume the same provider-neutral launch contract, but its UI, session, and navigation policy belong to the Browser domain.
