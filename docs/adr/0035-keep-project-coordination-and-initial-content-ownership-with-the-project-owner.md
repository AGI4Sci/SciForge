# Keep Project coordination and initial content ownership with the Project Owner

Every current Coordinator Agent must be owned by the Project Owner, and Coordinator transfer may select only another exact Agent owned by that same User. Run-0 also derives the initial content owner from the Project Owner; a future content-owner change requires a separate saga on the new content owner's Desktop, so neither coordination authority nor Provider administration can be borrowed from another member implicitly.
