# Keep local SciForge usable without cloud login

SciForge remains offline-first: local chat, Workspaces, models, and tools are usable without a cloud-authenticated SciForge User, while cloud Projects, remote Tasks, cross-user collaboration, registered remote Agents, and external-account authority require the corresponding identity. This preserves the desktop product's local utility and avoids a mandatory application-shell login gate, at the cost of maintaining an explicit boundary between Local Mode state and later connected identity.
