# SciForge 使用手册

_从第一次连接模型，到完成科研任务、保存证据并使用插件、自动化与 Cloud 协同。_

---

SciForge 是一个面向科学研究的本地 AI 工作台。Codex 或 Claude Code 负责执行任务；SciForge 把工作区、会话、科研工具、文件变更和研究记录组织在同一个桌面界面中。

## 从这里开始

第一次使用请先阅读 [快速开始](./Getting-Started.zh-CN.md)。它会带你完成模型配置、选择 AI 助手、打开工作区并运行第一个任务。

## 使用手册

| 顺序 | 页面 | 你会学到什么 |
| --- | --- | --- |
| 0 | [快速开始](./Getting-Started.zh-CN.md) | 在大约 5 分钟内完成第一个任务 |
| 1 | [模型runtime](./Runtimes-and-Models.zh-CN.md) | 配置模型 API 或 Coding Plan，选择 Codex / Claude Code |
| 2 | [科研工作流](./Scientific-Workflows.zh-CN.md) | 跟踪论文、复现实验、分析数据和制作图表 |
| 3 | [研究档案与证据](./Intervention-and-Data.zh-CN.md) | 保存结论、版本、来源与研究产物 |
| 4 | [插件、Skills 与 MCP](./Extensions-Skills-and-MCP.zh-CN.md) | 为助手增加领域能力、工作方法和工具 |
