## Live 复测矩阵

主聊天图片理解必须至少包含：

- 科研图表：轴标签、图例、误差条或多组曲线问答。
- 显微/实验图像：样本区域、标注、对照组差异问答。
- UI 截图：按钮、菜单、状态提示和局部小字问答。
- 复杂标注图片：小字、图例、坐标轴、局部 crop 补问。

固定材料必须存放为文件 refs，例如 `docs/test-artifacts/main-chat-image-understanding-live-matrix/materials/*.png`，并在 `tools/main-chat-image-understanding-live-matrix-cases.ts` 记录 ref、sha256、尺寸、来源/许可说明和最小答案概念 rubric。manifest 只保存答案摘要 hash/长度、rubric 覆盖计数和 trace refs；不得保存答案全文、图片 bytes、data URL/base64、raw provider payload、私密 URL 或本地绝对路径。

Computer Use 必须至少包含：

- 浏览器科研检索：检索、打开结果、提取可见证据 ref。
- 文档/表格编辑：创建或修改文件，并用 file/artifact refs 证明。
- 文件管理：定位、重命名、移动或打开目标文件。
- IDE/终端：运行命令或编辑代码，并用终端/file refs 证明。
- 跨窗口恢复与 verifier：目标窗口切换、失败诊断、复查后继续或 blocked。

Computer Use live gate 的 case id 必须严格为 `browser-research`、`docs-sheets-edit`、`file-management`、`ide-terminal`、`cross-window-recovery-verifier`。每个 passed case 必须有公开 Model Router alias/profile、workspace-file router trace refs、Computer Use capability ids、current-run desktop/native-host 或 app-window executor refs、native/session binding refs、对应的 screenshot/file/artifact/terminal/verifier refs，以及 workspace-file `gui.present`；blocked/repair refs 只能作为 blocked/repair 诊断，不能冒充 passed GUI evidence。缺少 `ide-terminal`、任一类别、source ref、manifest 文件、可解析 manifest 内容、外部 post-run trace audit report，或证据 ref 跨出声明的 current-run scope、使用 non-file/custom-scheme 或 embedded traversal ref、重复 normalized routerTraceRef、routerTraceRef 未被 trace audit scannedFileRefs 精确覆盖到 `trace.json` 时 gate 必须保持 blocked。`current-run.json` 必须是 `sciforge.model-router.computer-use.current-run.v1` marker，包含 runId、startedAt 和 completedAt，且 scoped evidence 文件时间必须落在该 marker 窗口内。每个 passed case 的 `gui.present` 和 verifier refs 必须是 `sciforge.model-router.computer-use.evidence.v1` JSON envelope，绑定同一 runId/caseId，并声明 `gui.present`/`present` 或 `verifier`/`passed`。每个 passed case 的 router `trace.json` 必须是 `sciforge.model-router.trace.v1`，匹配该 result 的 public alias/profile，并包含 ok `visionTranslator` 与 `textReasoner` calls。trace audit report 还必须有 `sciforge.model-router.trace-audit.v1` schema、trace root hash、`scannedFiles === scannedFileRefs.length`、positive `scannedBytes`、零 findings、expected positive `policy.knownSecretsChecked`、全部 no-secret policy flags，且 external report 文件时间不能早于 source manifest/input；输出只能是 workspace-relative ref 或短 hash ref，不能输出本地绝对路径或 Node stack trace。

Live 证据必须只保存 refs、hash、尺寸、router profile/alias、capability ids、round/error summary 和 bounded diagnostics。禁止保存 raw screenshot bytes、data URL/base64、raw provider request/response、API key、Authorization、secret、私密 URL 或本地绝对路径。
