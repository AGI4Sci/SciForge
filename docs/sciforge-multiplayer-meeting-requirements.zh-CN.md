# SciForge 多人协作讨论需求（简版）

本文定义两个独立的 SciForge Project 讨论场景。每个场景由一名项目发起人担任 Coordinator，邀请 3–5 名专家 Worker 分别讨论不同子议题。专家完成后把结论返回 Coordinator，由 Coordinator 汇总会议纪要。

## 场景一：深海生物制造产业创新中心

### 讨论主题

**深海生物制造产业创新中心下一阶段的发展重点：如何从中心现状出发，确定高价值海洋产品和海洋天然产物新药的优先方向，并形成可执行的产业化计划？**

### 项目发起人

**产业创新中心项目负责人（Coordinator）**

负责说明会议背景和目标，向专家派发子议题，收集并比较专家意见，确认最终决策和行动项。

### 专家角色与子议题

| 专家角色 | 专业背景 | 负责的子议题 |
| --- | --- | --- |
| 深海生物制造产业专家 | 熟悉深海资源开发、产业链、生产成本和规模化转化 | 中心当前进展、主要问题、产业能力短板，以及下一阶段的重点建设任务 |
| 海洋高值产品研发专家 | 熟悉海洋生物材料、功能产品和产品产业化 | 哪些高价值海洋产品最值得优先研发；目标市场、技术成熟度和产业化路径是什么 |
| 海洋天然产物新药专家 | 熟悉活性天然产物筛选、药物发现和先导开发 | 哪些海洋天然产物或生物活性方向值得优先投入；需要哪些筛选、验证和合作条件 |
| 技术与投资评估专家 | 熟悉科研项目评估、技术转移、投资回报和项目管理 | 比较候选方向的技术风险、投入产出、里程碑和资源配置建议 |

### Coordinator 需要汇总的结果

- 中心当前最需要解决的 3 个问题；
- 高价值海洋产品和海洋天然产物新药的优先方向；
- 每个优先方向的下一步任务、负责人和时间节点；
- 需要补充的资源、合作方和决策事项。

### 会议纪要验收标准

纪要必须清楚记录讨论主题、参会角色、各专家结论、已达成的优先级决策、行动项负责人和下一步时间节点；没有达成共识的内容必须列为待讨论事项。

## 场景二：蛋白质设计自进化 Agent

### 讨论主题

**如何为深海生物制造和海洋天然产物研发设计一个可持续自我改进的蛋白质设计 Agent，并确定它的首个落地任务、专家分工和验证方式？**

### 项目发起人

**蛋白质设计 Agent 项目负责人（Coordinator）**

负责确定 Agent 的目标和边界，拆分子议题，邀请专家 Worker，审核专家结果，并组织形成最终方案纪要。

### 专家角色与子议题

| 专家角色 | 专业背景 | 负责的子议题 |
| --- | --- | --- |
| 蛋白质工程专家 | 熟悉酶、抗体、结合蛋白、表达纯化和定向进化 | 首个设计任务选择：优先做酶、抗体还是结合蛋白；需要满足哪些序列、结构和功能约束 |
| 结构生物信息学专家 | 熟悉结构预测、序列生成、结构—序列协同设计和生物数据库 | Agent 应采用哪些结构/序列设计工具和数据；现有工具能解决什么，不能解决什么 |
| Agent 架构与机器学习专家 | 熟悉科研 Agent、模型协作、记忆管理和任务编排 | Agent 由哪些模块组成；不同专家 Worker 如何协作；设计结果如何进入下一轮优化 |
| 实验与评估专家 | 熟悉蛋白质活性、结合亲和力、稳定性实验和统计验证 | 如何验证 Agent 设计结果；成功率、活性、亲和力、稳定性等指标如何定义；需要多少计算和实验轮次 |
| 生物安全与治理专家 | 熟悉生物安全、双重用途、数据许可、知识产权和科研审批 | 哪些任务和工具需要人工确认；如何处理数据/IP、实验安全和成果发布风险 |

### Coordinator 需要汇总的结果

- 1–2 个首选蛋白质设计任务及选择理由；
- Agent 的主要模块和专家 Worker 分工；
- “设计—模拟—实验—反馈—再设计”的迭代方式；
- 成功指标、计算/实验硬约束和风险控制要求；
- 下一阶段的试点任务、负责人和交付时间。

### 会议纪要验收标准

纪要必须明确 Agent 的首个落地任务、每位专家的结论、整体方案、量化成功指标、硬约束、风险与人工确认点，以及下一步行动项；所有关键结论应注明由哪位专家提出或依据哪份资料得出。

## SciForge 中的共同协作方式

1. 项目发起人创建 Project，写明讨论主题和最终要回答的问题。
2. Coordinator 将不同子议题分别派给 3–5 名专家 Worker；每位专家只负责一个明确子议题。
3. Worker 在自己的 SciForge 会话中完成分析，并把结论、依据和建议返回 Coordinator。
4. Coordinator 审阅专家结果，处理分歧，确认决策和行动项，生成并发布会议纪要。
